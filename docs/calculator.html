How to use this tool

Enter the number of each source type for the customer site and the calculator will recommend the minimum server CPU SKU. Rates are pre-loaded from a 36-source, 4-day endurance test on a 16-core server - adjust the sliders to tune target utilization and headroom. If you have your own test run data, expand Advanced - Recalibrate Rates to plug in your measured values.

ⓘ Default rates measured from a 36-source, 4-day endurance test on a 16-core / 32 GB server (May 2026, overhead factor 1.526x). Hover any measured or estimated badge for details.
